# 🔐 Network Traffic Analysis Using Wireshark

## 📌 Project Overview

This is a beginner cybersecurity project where I used **Wireshark** to capture and analyze network traffic from my own system.

The goal was to understand network packets, IP addresses, and common network protocols.

## 🔍 What I Practiced

* Capturing network packets
* Identifying source and destination IP addresses
* Analyzing network protocols
* Filtering DNS traffic
* Filtering TCP traffic
* Analyzing ICMP traffic
* Using Wireshark display filters
* Reviewing individual packets

## 🛠️ Tool Used

* Wireshark

## 🔎 Filters Used

```text
dns
```

```text
tcp
```

```text
icmp
```

## 📚 What I Learned

Through this project, I learned the basics of **packet analysis, network traffic monitoring, IP addresses, and network protocols**.

This practice helped me understand how network traffic can be analyzed during SOC security monitoring and investigations.
